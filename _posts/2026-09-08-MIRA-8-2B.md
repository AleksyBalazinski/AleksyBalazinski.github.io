## Problem statement
Prove that the collection of Borel subsets of \\(\mathbb{R}\\) is translation invariant, i.e., prove that if \\(B \subseteq \mathbb{R}\\) is a Borel set and \\(t \in \mathbb{R}\\), then \\(tB = \{tb : b \in B\}\\) is a Borel set.

## Solution
This is an interesting problem because it's not obvious where to even start.
The definition of Borel set (an element of the smallest \\(\sigma\\)-algebra containing all open sets) doesn't seem to provide a good starting point.
After all, it doesn't tell us anything about what a Borel set "looks like" or how it is constructed.

The idea is to look at \\(\mathcal{A} = \{A \subseteq \mathbb{R} : tA \in \mathcal{B}\}\\) and show that \\(\mathcal{B} \subseteq \mathcal{A}\\) so that \\(\forall B \in \mathcal{B}, tB \in \mathcal{B}\\).
In order to show the inclusion, we'll prove that \\(\mathcal{A}\\) is a \\(\sigma\\)-algebra and that it contains all open sets.

### \\(\mathcal{A}\\) is a \\(\sigma\\)-algebra

1) \\(\phi \in \mathcal{A}\\) b/c \\(t\phi = \phi \in \mathcal{B}\\).

2) \\(E \in \mathcal{A} \iff tE \in \mathcal{B}\\).
   \\[t(\mathbb{R} \setminus E) = \mathbb{R} \setminus (tE) \in \mathcal{B} \implies \mathbb{R} \setminus E \in \mathcal{A}\\]

3) \\(E_1, E_2, \ldots \in \mathcal{A} \iff \forall j \in \mathbb{Z}^+, tE_j \in \mathcal{B}\\).
   \\[t\left(\bigcup_{j=1}^\infty E_j\right) = \bigcup_{j=1}^\infty (tE_j) \in \mathcal{B} \implies \bigcup_{j=1}^\infty E_j \in \mathcal{A}.\\]

### \\(\mathcal{A}\\) contains all open sets 
We'll prove this by showing that for every open set \\(G \subseteq \mathbb{R}\\), \\(tG\\) is also open.

Sp. \\(G \subseteq \mathbb{R}\\) is an open set and \\(t \neq 0\\).

Let \\(x \in tG\\). Then \\(x = tg\\) for some \\(g \in G\\).
We know that \\(\exists \varepsilon > 0\\) s.t. \\(V_\varepsilon(g) = (g - \varepsilon, g + \varepsilon) \subseteq G\\).

Consider the neighborhood \\(V_{\lvert t \rvert\varepsilon}(x)\\). For any \\(y \in V_{\lvert t \rvert\varepsilon}(x)\\):
\\[\lvert y - x \rvert < \lvert t \rvert\varepsilon \iff \lvert y - tg \rvert < \lvert t \rvert\varepsilon\\]
\\[\iff \left\lvert \frac{y}{t} - g\right \rvert < \varepsilon \implies \frac{y}{t} \in V_\varepsilon(g) \subseteq G.\\]

Thus \\(y = t\left(\frac{y}{t}\right) \in tG\\), which proves \\(V_{\lvert t \rvert\varepsilon}(x) \subseteq tG\\).
Hence \\(tG\\) is open.

### Conslusion
So for any open \\(G \subseteq \mathbb{R}\\), \\(tG\\) is also open & hence Borel. Thus \\(\mathcal{A}\\) is a \\(\sigma\\)-algebra that contains all open sets. \\(\mathcal{B}\\) is the smallest \\(\sigma\\)-algebra containing all open sets so \\(\mathcal{B} \subseteq \mathcal{A}\\) (\\(\mathcal{A}\\) contains all Borel sets);

\\[\forall B \in \mathcal{B}, B \in \mathcal{A} \iff \forall B \in \mathcal{B}, tB \in \mathcal{B}.\\]
